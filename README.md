# 游话好说 — 游戏角色外号百科

《Web前端设计与开发实训》大作业（优秀档 B）项目。一个查询游戏角色外号的网站，数据覆盖原神、王者荣耀、英雄联盟、崩坏：星穹铁道四款游戏，支持外号浏览、检索、投稿与审核，内置完整的 RBAC 权限体系。

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 框架 | Vue 3（`<script setup>` 组合式 API） |
| 语言 | TypeScript |
| 构建 | Vite 5 |
| UI 组件库 | Element Plus（中文语言包） |
| 状态管理 | Pinia + localStorage 持久化 |
| 路由 | Vue Router 4（静态路由 + `addRoute` 动态路由 + 全局守卫鉴权） |
| 图表 | ECharts 5 |
| 数据层 | fetch 封装（请求/响应拦截器）+ Mock 接口层 |

## 环境要求

- Node.js ≥ 18
- npm ≥ 8

## 启动步骤

```bash
# 1. 进入项目目录
cd nickname-hub

# 2. 安装依赖
npm install

# 3. 启动开发服务器（默认 http://localhost:5173/）
npm run dev

# 4. 生产构建（产物输出到 dist/）
npm run build

# 5. 本地预览生产构建产物
npm run preview
```

> 项目使用 Mock 数据层（`src/apis/mockdb.ts`），无需后端服务，也无需配置环境变量。生产构建产物部署到任意静态服务器（Nginx / Vercel / GitHub Pages 等）即可访问。

## 演示账号

系统内置三个角色账号，密码均为 `123456`：

| 账号 | 角色 | 权限说明 |
| --- | --- | --- |
| `admin` | 超级管理员 | 全部 14 个权限点：所有菜单 + 外号增删改/导出、投稿审核、角色权限分配、投稿删除等高危操作 |
| `editor` | 内容编辑 | 12 个权限点：外号管理与导出、投稿审核，但**不能**分配角色权限、不能删除投稿 |
| `user` | 普通用户 | 5 个权限点：仪表盘、外号浏览（只读）、角色详情、投稿、个人中心 |

切换不同账号登录，可直观对比菜单动态变化与按钮级权限差异（如普通用户在列表页看不到"新增/编辑/删除/导出"按钮）。

## RBAC 权限模型

- 用户 → 角色 → 权限点集合（`src/data/seed.ts` 中的 `PERMISSION_TREE`）
- 登录后汇总角色权限写入 Pinia 并持久化到 localStorage
- 侧边菜单根据权限**动态渲染**（动态路由按权限 `addRoute` 注入）
- 按钮级权限使用自定义指令 `v-permission` 控制
- 角色权限页提供 `el-tree` 权限树勾选编辑，保存后重新登录即生效
- 无权限访问页面跳转 `/403`，未匹配路由跳转 `/404`

## 数据说明

- 所有演示数据（外号库 40+ 条、投稿、角色、用户）存储在浏览器 **localStorage**（键前缀 `nhub_`）
- 想恢复初始演示数据：打开浏览器控制台执行 `localStorage.clear()` 后刷新页面即可重新加载种子数据
- 外号列表页支持一键导出 CSV（UTF-8 BOM 编码，Excel 直接打开不乱码）

## 页面清单（10 个页面，5 类以上）

1. 登录页（表单校验、演示账号快捷填充）
2. 仪表盘（ECharts：各游戏外号数量柱状图 + 热度分布饼图）
3. 外号列表（业务模块一：表格布局——筛选/分页/弹窗新增编辑/批量删除确认/CSV 导出）
4. 角色详情（按需加载外号子数据"加载更多"、截图附件预览与下载）
5. 投稿页（业务模块二：分步表单布局——步骤条 + 图片上传预览）
6. 投稿审核（卡片流布局：通过/驳回确认弹窗、采纳入库）
7. 角色权限管理（权限树勾选）
8. 个人中心（资料修改、头像预览）
9. 403 无权限页
10. 404 未找到页
